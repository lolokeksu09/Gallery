# Gallery

Personal offline AMOLED gallery for Android 13+. Kotlin and Jetpack Compose.

## Privacy
No INTERNET permission, analytics, accounts, cloud services or background services. Photos permission is required to browse the photo library; video permission is optional. Deletion requires Android confirmation.

## Development
See docs/SPEC.md, docs/ARCHITECTURE.md and docs/PROGRESS.md. GitHub Actions builds the APK; physical-device testing remains required before a stable release.
